FREQUENTLY ASKED QUESTIONS

SYSTEM & DEPLOYMENT FAQ

HOW DOES AEGIS PREVENT LLM HALLUCINATIONS? +
Aegis enforces a strict zero-hallucination constraint by building a directional NetworkX evidence graph. Every output claim must map directly to a verified source node in ChromaDB/BM25, or the citation compiler rejects the statement.
WHY IS DOCKER SANDBOXING REQUIRED? +
To execute code generated by research agents without risking the host system, Aegis runs an air-gapped Docker sandbox container with isolated network policies and automated workspace snapshot rollbacks.
CAN AEGIS RUN FULLY OFFLINE OR AIR-GAPPED? +
Yes! Aegis supports local LLM providers like Ollama alongside vector databases (ChromaDB) and local file RAG, enabling 100% air-gapped enterprise deployments.
HOW DO I LAUNCH THE FULL STACK LOCALLY? +
Run python launcher.py in the terminal. It initializes the FastAPI Sandbox microservice on port 8000 and the Streamlit dashboard on port 8501.
